# Toy-Lab

> 一个非全栈、非游戏的趣味代码仓库。  
> 收录我在不同语言里写的小工具和小玩具，纯粹为了好玩。

支持语言：`C` · `C++` · `Python` · `Go` · `Java` · `Web`

---

## 这是什么

这里不是一个完整的项目，也不是一套成体系的框架。

这里只放一些让我觉得“有意思”的东西——  
可能是一个奇怪的小工具，一段实验性代码，或者一个偶然冒出的小想法。

它们可以不够实用，可以不够严谨，  
但写的时候得让我开心。

---

## 语言分类

| 语言 | 目录 | 内容方向 |
|------|------|----------|
| C | `c/` | 内存操作、系统级小实验、算法玩具 |
| C++ | `cpp/` | 模板、手写容器、底层小工具、趣味算法 |
| Python | `python/` | 脚本、数据处理、自动化、奇怪玩法 |
| Go | `go/` | 并发、网络、命令行小工具 |
| Java | `java/` | 语法实验、JVM 玩法、小工具 |
| Web | `web/` | 动画、交互、视觉玩具、终端模拟 |

---

## 收录标准

一个东西能进这个仓库，至少满足一条：

- 写的时候让我觉得“这个有意思”
- 能学到某个语言或某个概念的新东西
- 虽然是玩具，但代码是认真写的
- 以后回头看，还能笑一笑

不符合的：

- 烂大街的练习题
- 为了凑数硬塞的 demo
- 半成品全栈项目
- 游戏

---

## 特色

> 每个项目都有对应的`prompt`或`Agent Skill`供大家指导AI开发
> 作者的demo不一定好，每个人的需求也不一样，大家可以根据自己的喜欢工具拿到对应的提示词
> 直到AI改出你想要的效果，或配置自己的 AI `Syetem Prompt`、以及 `Skill`

## 目录结构

```
Toy-Lab/
├── c/          # C 语言玩具
├── cpp/        # C++ 玩具与工具
├── python/     # Python 脚本与实验
├── go/         # Go 语言小玩意
├── java/       # Java 实验
├── web/        # 网页动画与交互玩具
└── README.md
```

每个语言目录里可以有多个独立的子项目，每个子项目自己带说明。

---

## 使用方式

进入对应语言目录，按各子项目里的说明运行。

大部分玩具都力求简单直接，不依赖复杂环境。
