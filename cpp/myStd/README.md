# myStd — 手搓 C++ 标准库

## 这是什么？

`myStd` 是一个**从零开始手搓的 C++ 标准库实现**，目前仅包含 `vector` 动态数组组件，设计目标是模仿 C++ 标准库（std）的行为，同时遵循个人编码风格。

这**不是要替代标准库**，而是为了：
- 深入理解 C++ 标准库的内部实现机制
- 学习模板元编程、内存管理、异常安全
- 提供一个可读性强、注释详尽的教学版本

---

## 与标准库的宏观差异

| 维度 | 标准库（std） | myStd（本实现） |
|------|-------------|----------------|
| **命名空间** | `std` | `myStd::STL` |
| **接口设计** | 完全遵循 C++ 标准 | 在核心接口上保持一致，但部分签名简化（如用索引替代迭代器） |
| **边界检查** | `operator[]` 不检查，`at()` 检查 | `operator[]` 也检查（与 `at()` 等效），更安全但略慢 |
| **迭代器** | 专用迭代器类型，支持 debug 模式 | 直接用原生指针（`T*`），更轻量，但失去越界调试信息 |
| **异常安全** | 标准要求强异常保证 | 同样保证强异常安全（reallocate 失败时回滚） |
| **模块支持** | 使用传统头文件 | 支持 C++20 模块（`export module`） |
| **扩展接口** | 标准委员会控制 | 自由增加便利接口（如 `erase_range`、`append_range`） |

## 核心设计取舍

### 与标准库保持一致的地方

- **内存布局**：连续存储，缓存友好
- **扩容策略**：倍增容量（因子 2），均摊 O(1)
- **移动语义**：支持移动构造和移动赋值
- **分配器支持**：可自定义内存分配器
- **强异常安全**：扩容失败时原对象不变，不泄漏内存

### 与标准库不同的地方

- **`operator[]` 带边界检查**：标准库不检查，本实现检查（越界抛异常），偏向安全而非性能
- **`insert` / `erase` 使用索引**：标准库用迭代器，本实现用 `std::size_t idx`，更直观但牺牲了与标准算法的兼容性
- **原生指针迭代器**：标准库迭代器通常为类类型，本实现直接使用 `T*`，零开销但功能有限
- **范围操作只支持 initializer_list**：标准库支持任意迭代器对，本实现简化到 `std::initializer_list`
- **新增便利接口**：`erase_range(idx, count)` 等，标准库无直接对应
