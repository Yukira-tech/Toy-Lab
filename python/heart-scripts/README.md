# 爱心弹窗生成器

## 项目简介

本项目提供一个 Python 脚本，使用 tkinter 在屏幕上生成大量彩色弹窗。这些弹窗先按笛卡尔心形公式排列成一颗爱心，然后逐个随机移动到屏幕各处，最终铺满整个屏幕。整个过程无需关闭或重建窗口，仅通过改变窗口位置实现平滑动画。

---

## 文件说明

本目录包含以下三个核心文件，分别面向不同使用场景：

### 1. `heart_popup.py`

这是最终生成的 Python 脚本，直接运行即可看到效果。它包含所有参数、样式和动画逻辑，是最终产物。

### 2. `skill.md`

**这是给 AI Agent（如自定义 GPT、Claude Assistant 或您自己搭建的智能体）使用的技能定义文件。**  
它的作用是：

- 告诉 AI 如何处理“爱心弹窗”类的用户需求。
- 规定了脚本的生成步骤、参数命名、动画流程、样式细节等。
- 让 AI 在生成代码时有一致的行为，避免出现偏离需求的情况。

如果您是开发者，想配置一个专门生成此类脚本的 AI 助手，可以将 `skill.md` 的内容作为系统提示词或知识库注入。

### 3. `prompt.txt`

**这是给普通用户直接使用的提问模板。**  
它的作用是：

- 用户只需复制 `prompt.txt` 中的全部文字，粘贴到任何 AI 对话窗口（如 ChatGPT、Claude、文心一言等），AI 就会按照要求生成完整的 Python 脚本。
- 它降低了用户描述需求的门槛，确保 AI 理解准确，避免反复沟通。

### 三者关系

- `skill.md` 是给 AI 开发者（或高级用户）配置 Agent 用的，属于“元指令”。
- `prompt.txt` 是给最终用户直接发问用的，属于“现成提问”。
- `heart_popup.py` 是 AI 根据上述指令或提问生成的最终产物。

您可以根据自己的角色选择使用：

- 如果您只是想要效果，直接复制 `prompt.txt` 发给 AI 即可。
- 如果您想搭建一个专用机器人，请参考 `skill.md` 配置。

## 主要特色

- 使用笛卡尔心形参数方程计算弹窗坐标，形成标准爱心形状。
- 每个弹窗拥有独立的彩色背景和随机暖心文字。
- 弹窗顶部固定白色标题栏，带有分割线和固定标题文字。
- 文字颜色根据背景亮度自动选择深色或白色，确保清晰可读。
- 动画分两阶段：心形逐个生长，然后逐个随机散开铺满屏幕。
- 所有弹窗无系统边框，保持屏幕最前显示。
- 整个过程不销毁窗口，只移动位置，性能稳定。

## 参数说明

脚本顶部包含可调节参数，用户可根据需要修改：

| 参数 | 默认值 | 作用 |
|------|--------|------|
| TOTAL | 250 | 弹窗总数，建议 200-400 |
| HEART_SCALE | 20 | 心形整体大小，数值越大心形越舒展 |
| X_OFFSET | -90 | 心形水平偏移，负值向左移 |
| Y_OFFSET | -115 | 心形垂直偏移，负值向上移 |
| WIN_WIDTH | 220 | 每个弹窗的宽度 |
| WIN_HEIGHT | 100 | 每个弹窗的高度 |
| SLEEP_CREATE | 0.008 | 生成每个弹窗的间隔时间，控制生长速度 |
| SLEEP_SCATTER | 0.005 | 移动每个弹窗的间隔时间，控制散开速度 |

---

## 颜色与文字

- 背景颜色从预定义柔和色列表中随机选取，包含 `pink`, `lightblue`, `lightgreen`, `lemonchiffon` 等。
- 文字列表包含 35 条暖心祝福语，可自由增删。
- 标题栏固定显示文字“爱心小提醒”，可修改。
- 文字颜色根据背景亮度自动适配，浅色背景用深色文字，深色背景用白色文字。

## 运行方法

1. 确保系统已安装 Python 3（tkinter 为内置库，无需额外安装）。
2. 将脚本代码保存为 `heart_popup.py`。
3. 在终端或命令行中运行：

   ```bash
   python heart_popup.py
   ```

4. 脚本运行后会自动全屏展示，完成后自动关闭。

## 自定义指南

- 调整心形大小和位置：修改 `HEART_SCALE`、`X_OFFSET`、`Y_OFFSET`。
- 改变弹窗尺寸：修改 `WIN_WIDTH` 和 `WIN_HEIGHT`。
- 更换文字内容：编辑 `TEXTS` 列表。
- 更换背景颜色：编辑 `COLORS` 列表。
- 调整动画速度：修改 `SLEEP_CREATE` 和 `SLEEP_SCATTER`。
- 修改标题栏文字：修改 `TITLE` 变量的值。

## 注意事项

- 弹窗数量过多时可能占用较多系统资源，建议不超过 400 个。
- 部分系统可能对无边框窗口的置顶效果支持不同，若遇到窗口被遮挡可尝试调整。
- 脚本运行期间会持续刷新窗口，请勿在关键工作场景下运行。
