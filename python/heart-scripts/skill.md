# 爱心弹窗生成技能（移动铺满版）

## 功能概述
- 使用 Python 的 tkinter 创建大量无边框弹窗。
- 弹窗按笛卡尔心形公式排列，呈现爱心形状。
- 弹窗样式定制：白色标题栏 + 彩色背景 + 自适应文字颜色。
- 动画流程：心形逐个生成 → 逐个随机移动铺满屏幕 → 停留后自动退出。

## 适用场景
- 制作惊喜祝福程序（如节日礼物、表白等）。
- 演示 tkinter 多窗口动画。
- 自定义弹窗样式练习。

## 核心参数（可调）
| 参数 | 默认值 | 说明 |
|------|--------|------|
| TOTAL | 250 | 弹窗总数（建议 200~400） |
| HEART_SCALE | 20 | 心形整体缩放系数 |
| X_OFFSET | -90 | 心形水平偏移（负值左移） |
| Y_OFFSET | -115 | 心形垂直偏移（负值上移） |
| WIN_WIDTH | 220 | 弹窗宽度 |
| WIN_HEIGHT | 100 | 弹窗高度 |
| SLEEP_CREATE | 0.008 | 生成每个弹窗的间隔（秒） |
| SLEEP_SCATTER | 0.005 | 移动每个弹窗的间隔（秒） |

## 颜色与文字
- 背景颜色预定义柔和色列表（至少 16 种）。
- 文字列表包含至少 35 条暖心祝福语（可扩展）。
- 根据背景亮度自动选择文字颜色（浅色背景用深色，深色背景用白色）。
- 标题栏固定文字 "💌 爱心小提醒"。

## 实现步骤
1. **导入库**：tkinter, random, math, time。
2. **定义辅助函数**：
   - `get_seg(t, scale)`：返回心形坐标偏移。
   - `is_light_color(color_name)`：判断颜色深浅。
   - `make_styled_window(root, x, y)`：创建单个带标题栏和彩色主体的弹窗。
3. **主程序**：
   - 获取屏幕尺寸，计算心形基准点（中心 + 偏移）。
   - 循环生成 `TOTAL` 个弹窗，每个位置由心形公式计算，间隔 `SLEEP_CREATE` 秒。
   - 心形完整后，预计算所有随机目标位置（避免移动时卡顿）。
   - 逐个移动弹窗到随机位置，间隔 `SLEEP_SCATTER` 秒，最后一个不等待。
   - 停留 3 秒后销毁所有窗口。

## 注意点
- 弹窗使用 `overrideredirect(True)` 去掉系统边框，确保无标题栏。
- 移动时使用 `win.geometry(f"+{rand_x}+{rand_y}")` 直接改变位置，不重建窗口。
- 随机坐标需减去弹窗宽高，确保不超出屏幕。
- 标题栏和主体通过 Canvas 绘制，分割线增强层次感。
- 文字阴影增加视觉效果，但非必须。

## 使用示例
直接运行脚本即可，无需额外参数。若需调整效果，修改顶部的参数常量。
