# 账单管理系统 — Python Tkinter 桌面应用

## 项目简介

这是一个基于 Python Tkinter 的轻量级账单管理桌面应用程序，支持用户登录/注册、账单的增删查改以及按类型筛选等功能。数据以 JSON 和 JSONL 格式本地存储，无需数据库即可运行。

---

## 核心功能

- **用户管理**：登录、注册（支持显示密码）
- **账单管理**：
  - 添加账单（类型、名称、价格、备注）
  - 按类型筛选（全部 / 支出 / 收入）
  - 删除选中账单
  - 刷新列表
- **数据持久化**：所有账单以 JSONL 格式逐行存储

---

## 技术栈

- Python 3.x
- Tkinter（GUI 框架）
- JSON / JSONL（数据存储）
- 标准库（os, json, time, random）

---

## 文件说明

| 文件名 | 说明 |
|--------|------|
| `users.json` | 单用户账号信息（`{"account": "", "password": ""}`） |
| `bills.jsonl` | 账单数据（每行一个 JSON 对象） |
| `main.py` | 主程序入口（上述代码） |

---

## 运行方法

1. 确保已安装 Python 3（无需额外安装第三方库）。
2. 将代码保存为 `main.py`。
3. 在终端执行：

   ```bash
   python main.py
   ```

4. 首次运行会自动生成 `users.json` 和 `bills.jsonl` 文件。

---

## 操作流程

### 1. 注册账号
- 输入账号、密码、确认密码，点击注册。
- **注意**：本程序仅支持单用户（注册后无法再次注册新账号）。

### 2. 登录
- 输入已注册的账号和密码。
- 勾选“显示密码”可查看明文密码。

### 3. 添加账单
- 选择类型（支出 / 收入）
- 填写名称（必填）
- 填写价格（必填）
- 填写备注（选填）
- 点击“添加账单”

### 4. 筛选账单
- 从下拉框选择“全部 / 支出 / 收入”
- 点击“应用筛选”

### 5. 删除账单
- 在表格中选中要删除的行（点击行首）
- 点击“删除选中账单”

## 数据存储格式

### users.json（用户信息）

```json
{
  "account": "admin",
  "password": "123456"
}
```

### bills.jsonl（账单数据，JSONL 格式）

```
{"type": "支出", "name": "午餐", "price": "25", "tip": "黄焖鸡米饭", "id": 1709123456789}
{"type": "收入", "name": "兼职", "price": "200", "tip": "周末家教", "id": 1709123456790}
```

## 与标准实现的差异（设计取舍）

| 特性 | 标准账单系统 | 本实现 |
|------|-------------|--------|
| **用户体系** | 多用户管理 | 单用户（简化设计） |
| **数据格式** | JSON 数组或数据库 | JSONL 行格式（追加友好） |
| **ID 生成** | 自增 ID 或 UUID | 时间戳 + 随机数 |
| **删除方式** | 软删除或回收站 | 直接从文件重写 |
| **筛选** | 多条件组合 | 仅按类型筛选 |
| **导出导入** | 常有 | 无 |

---

## 注意事项

1. **密码明文存储**：当前版本未做加密，仅供学习/本地使用，**请勿用于生产环境**。
2. **删除操作**：删除后数据直接从文件移除，无法恢复，请谨慎操作。
3. **单用户限制**：注册后无法再注册新账号，如需重置，可手动清空 `users.json` 内容。
4. **JSONL 格式**：每行一条记录，追加写入效率高，但修改/删除时需重写整个文件。

## 可能遇到的问题及解决

| 问题 | 解决方法 |
|------|----------|
| 打开程序闪退 | 检查当前目录是否有写入权限 |
| 账单列表为空 | 确保 `bills.jsonl` 文件存在且格式正确 |
| 删除失败 | 检查账单是否有 `id` 字段（旧版本会自动补） |
| 注册失败 | 当前已有注册用户时无法再次注册，清空 `users.json` 后重试 |
