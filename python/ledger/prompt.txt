我需要一个 Python Tkinter 账单管理程序。

## 技术栈
- Python 3.x
- Tkinter（GUI）
- 标准库：json, os, time, random

## 数据存储
- users.json：存储单用户账号，格式 {"account": "", "password": ""}
- bills.jsonl：存储账单，每行一个 JSON 对象，包含 type, name, price, tip, id

## 文件初始化要求
程序启动时自动检查并创建 users.json 和 bills.jsonl（若不存在）。

## 页面与功能

### 1. 登录页面
- 账号输入框
- 密码输入框（默认隐藏，提供“显示密码”复选框）
- “登录”按钮：校验账号密码是否匹配 users.json
- “去注册”按钮：切换到注册页面

### 2. 注册页面
- 账号输入框
- 密码输入框（默认隐藏）
- 确认密码输入框
- “显示密码”复选框（同时控制密码和确认密码）
- “注册”按钮：校验非空、两次密码一致、且当前无注册用户（单用户模式），通过则写入 users.json
- “去登录”按钮：切换到登录页面

### 3. 账单管理主页
- 筛选栏：下拉框（全部 / 支出 / 收入）+ “应用筛选”按钮
- 新增表单：类型（支出/收入）、名称、价格、备注（tip）
  - “添加账单”按钮：名称和价格必填，写入 bills.jsonl，清空输入框，刷新表格
- 表格（Treeview）：显示 type, name, price, tip 四列
- “删除选中账单”按钮：获取选中行的 id，从 bills.jsonl 中移除，重写文件，刷新表格
- “刷新列表”按钮：重新加载 bills.jsonl 并根据当前筛选刷新表格

## 工具函数要求
- init_file()：初始化数据文件
- load_user() / save_user()：读写用户信息
- load_all_bills()：加载所有账单，若旧记录无 id 字段则自动补一个（时间戳+随机数）
- append_bill_record(item)：新增账单，自动生成 id（时间戳+随机数），以 JSONL 格式追加
- rewrite_all_bills(bills)：用新列表覆盖整个 bills.jsonl

## 页面切换逻辑
- 使用 App 类管理当前页面
- 提供 goto_login()、goto_register()、goto_main() 方法切换
- 切换时销毁当前页面对象

## 约束
- 密码明文存储（不加密，仅供学习）
- 单用户模式（注册后不可再注册）
- 删除为永久删除
- 所有操作通过 GUI 触发，无命令行交互

## 输出要求
- 输出一个完整的 Python 脚本，可直接运行
- 包含所有必要的 import
- 代码顶部包含文件初始化调用
- 所有类和函数包含中文注释，说明用途和关键逻辑
