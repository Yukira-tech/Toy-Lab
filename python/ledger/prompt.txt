# ================================================================
# 账单管理系统 — 提示文档（Prompt）
# ================================================================

## 项目概述
这是一个基于 Python Tkinter 的轻量级账单管理桌面应用程序。
它使用本地 JSON / JSONL 文件存储数据，无需数据库，开箱即用。
主要功能包括用户登录/注册、账单的添加/删除/筛选以及表格展示。

## 功能列表
1. 用户管理
   - 注册（仅支持单用户，注册后不可再次注册）
   - 登录（支持显示密码）
2. 账单管理
   - 添加账单（类型、名称、价格、备注）
   - 按类型筛选（全部 / 支出 / 收入）
   - 删除选中的账单
   - 刷新列表

## 技术栈
- Python 3.x
- Tkinter（GUI 框架）
- 标准库：json, os, time, random

## 数据存储格式
- users.json：单用户账号信息，格式为 {"account": "", "password": ""}
- bills.jsonl：每行一个 JSON 对象，包含 type, name, price, tip, id（自动生成）

## 运行方法
1. 将代码保存为 main.py。
2. 在终端执行：python main.py
3. 首次运行会自动生成数据文件。

## 设计取舍与注意事项
- 单用户设计：简化应用结构，适合个人使用。
- 密码明文存储：未加密，仅适合本地/学习场景，不可用于生产。
- JSONL 存储：追加高效，但删除/修改需要重写整个文件。
- ID 生成：基于时间戳+随机数，可满足单机使用需求。
- 删除操作：永久删除，无回收站，请谨慎操作。

## 代码结构说明
- 全局函数：文件初始化、读写用户信息、读写账单数据。
- 登录页面类 (LoginPage)
- 注册页面类 (RegisterPage)
- 账单管理主页类 (BillMainPage)
- 应用控制类 (App) 负责页面切换
