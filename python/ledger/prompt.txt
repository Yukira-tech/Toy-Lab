我需要实现一个基于 Python Tkinter 的账单管理桌面应用程序。

功能需求：

1. 用户管理
   - 注册：仅支持单用户（注册后不可再次注册），需要账号、密码、确认密码，密码输入框默认隐藏字符，提供“显示密码”复选框同时控制密码和确认密码的可见性。注册时校验非空、两次密码一致，且当前无注册用户，通过后保存到 users.json 文件。
   - 登录：账号、密码输入，提供显示密码复选框，登录按钮校验账号密码是否匹配 users.json，成功则进入主页面，失败弹出错误提示。
   - 登录和注册页面尺寸为 600x500，居中显示，不可调整大小。

2. 账单管理主页面
   - 窗口尺寸 600x550，不可调整大小。
   - 筛选栏：一个下拉框（选项：全部、支出、收入）和“应用筛选”按钮，点击后按类型过滤表格显示。
   - 新增账单区域（标签框）：类型（支出/收入下拉框）、名称（输入框）、价格（输入框）、备注tip（输入框）。“添加账单”按钮：名称和价格不能为空，自动生成 id（时间戳+随机数），以 JSONL 格式追加到 bills.jsonl 文件，然后清空输入框，刷新表格。
   - 表格（Treeview）：显示类型、名称、价格、备注tip 四列，高度 11 行，带垂直滚动条。
   - 工具栏：两个按钮：“删除选中账单”和“刷新列表”。删除时获取选中行的 id，从 bills.jsonl 中移除该记录，重写整个文件，刷新表格。若未选中则弹出提示。

3. 数据存储
   - users.json：存储单用户账号，格式 {"account": "", "password": ""}，首次运行自动创建。
   - bills.jsonl：每行一个 JSON 对象，包含 type, name, price, tip, id。首次运行自动创建空文件。
   - 所有读写操作需处理异常，避免程序崩溃。

4. 工具函数要求
   - init_file()：创建 users.json 和 bills.jsonl（若不存在）。
   - load_user() / save_user(account, password)。
   - load_all_bills()：加载所有账单，若某条记录缺少 id 字段，自动补一个（时间戳+随机数）。
   - append_bill_record(item)：新增账单，自动生成 id，以追加模式写入 bills.jsonl。
   - rewrite_all_bills(bills)：用新列表覆盖 bills.jsonl。

5. 页面切换
   - 使用 App 类管理当前页面（page 变量）。
   - 提供 goto_login()、goto_register()、goto_main() 方法，切换时先销毁当前页面对象。

6. 界面风格
   - 使用 ttk 组件，字体为 SimHei（黑体）。
   - 登录/注册页面的标题为“用户登录”和“用户注册”，字号 22。
   - 所有按钮文字为中文。

7. 约束
   - 密码明文存储（不加密，仅供学习）。
   - 单用户模式，注册后不可再次注册新账号。
   - 删除为永久删除，无回收站。
   - 所有操作通过 GUI 触发，无命令行交互。

输出要求：
   - 输出一个完整的 Python 脚本（.py），可直接运行。
   - 包含所有必要的 import 语句。
   - 程序启动时自动调用 init_file()。
   - 所有类和函数必须包含中文注释，说明用途和关键逻辑。
